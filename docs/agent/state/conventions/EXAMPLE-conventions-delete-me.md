This is for decisions a new agent cannot guess by reading the code, and that are
not hard rules of the contract. Examples: which package manager to use, why that
library and not the obvious one, which branch is the release branch.

If a convention really matters, **it also has a check in CI**. Without
verification, in two months nobody follows it.
